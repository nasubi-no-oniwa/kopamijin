# 木っ端みじん

C4を好きな所にくっつけて、起爆。犬小屋から車、家、船、飛行機、ビルまで、全10面を木っ端みじんにする3Dゲーム。

- マイクラのスペクターモードのように自由に飛び回れる（左側をなぞって進む・右側をなぞって見回す・▲▼で上下）
- 見えている所をタップするとC4がくっつく。何個でも置けて、「1つ戻す」で取り消せる
- 「起爆」でまとめて爆発。支えを失った所は崩れ落ち、オレンジのタンクは誘爆する
- ブロックの90%を吹き飛ばしたら成功。C4が少なく、早いほど高い点（面ごとのランキング）
